THESIS
The Granola notetaker tab in the Wispr Flow hub, rebuilt as a faithful clone of the real Granola app from six pinned screenshots. The visitor's job: review meeting notes, read transcripts, and record new meetings — without ever leaving the hub or opening a second window.

OWN-WORLD
The screenshots are the committed identity, not inspiration. Near-black #18181b shell; EB Garamond serif display titles ("Coming up", note titles); Figtree body; teal #22d3ee event accents; speaker colors #e07a5f / #a3e635; #84cc16 resume; ~760px centered column; thin-border pill buttons; dashed dividers. The world lends only type, palette, density, and one signature move — the shell stays a standard working product.

STORY
Open the Notetaker tab → see the dashboard (calendar card, suggested follow-ups, recent notes) → click a note → serif-titled detail with #-gutter section headings → open the transcript drawer via the waveform pill → read colored-speaker bubbles → hit "Resume" to record a new meeting, live turns streaming into the drawer from the local recorder backend.

FIRST VIEWPORT
Dashboard: serif "Coming up" header with nav arrows, Invite/+ New note pills; calendar card with teal left-border events and dashed dividers; Gmail suggested-follow-up banner; Today/Yesterday note rows with purple avatar and customer pill; floating "Ask anything" command pill at bottom. Signature move lives in the note detail's bottom dock: animated waveform pill that opens the transcript drawer.

FORM
Operate mode. Density: 760px column, 24/32px padding, 8px-radius cards on #1f1f23 surfaces. Pills: 1px #3f3f46 borders, rounded-full. Bubbles: #38383c left others, #2a2a2e right self. Timestamp dividers centered grey. Real pt-BR content from memory/db meetings via flowNative.

FINISH
unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
