# Primeira Nota com o Flow

O Flow agora salva todas as suas notas diretamente como arquivos Markdown (.md) na pasta `memory/notes/` e com banco SQLite local em `memory/db.db`.

Você pode editar seus arquivos em qualquer editor (Obsidian, VSCode) que o Flow manterá tudo sincronizado!
